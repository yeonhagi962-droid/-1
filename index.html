⚡ 전기기능사 실기 · 시퀀스 회로 시뮬레이터

예제
두 손가락으로 확대·축소, 빈 곳을 끌어 이동 (오른쪽 위 버튼: 전체/제어회로/전원부). 폰은 가로로 돌리면 더 크게 보여요.
실행 모드: 버튼을 누르고(터치 유지) 있으면 동작 · 편집 모드(터치 가능): 부품을 끌어 이동, 단자(○)를 차례로 탭해 배선, 퓨즈 출력 단자(P1, P2)를 탭해 연결, 선을 누르면 삭제, 부품 선택 후 라벨 변경/회전(R키)/삭제. 타이머·플리커 시간은 편집 모드에서 부품을 선택하고 '시간 −/+' 버튼으로 조절합니다. 리미트 스위치(LS)는 실행 모드에서 탭할 때마다 작동/해제가 바뀝니다. 수위센서(탱크)를 탭하면 수위가 상한→중간→하한→중간→상한 순으로 바뀌고, 플로트레스(FL)는 하한 이하에서 동작해 상한에 닿으면 복귀합니다. 센서가 없으면 FL 부품을 직접 탭해 수위를 바꿉니다. 전원부(TB1·MCCB·EOCR·MC·모터)는 왼쪽에 고정되어 있고 '전원부' 버튼으로 도면(M1·M2)·정역·Y-Δ 결선을 바꿀 수 있으며, 제어회로 배선은 퓨즈 출력 단자 P1·P2에서 시작합니다. MCCB를 탭하면 ON/OFF, 끊어진 퓨즈를 탭하면 교체됩니다. 학습용 단순 논리 시뮬레이션이므로 실제 도면은 공단 공개문제와 대조하세요.
